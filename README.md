# 绝对值破局者 · 学生端

网站：https://ding0180.github.io/absolute-value-breakthrough/

学生输入姓名即可学习，不需要密码或 GitHub 账号。当前浏览器按姓名保存进度。顶部和学习完成页均可导出 JSON 记录，未完成也能导出。学生需自行将文件发给老师。

教师使用现有“绝对值破局者_教师端.html”的“批量导入学生记录”功能。兼容 student-report v1 / absolute-value-breakthrough-2026-v1，包含各关检测、首次及最近作答、探究、观察记录和出门条。此网站不会自动上传学生记录。

同名学生请在姓名后加学号；换设备、换浏览器或清除浏览器数据不会自动找回进度。网页全部资源内嵌。
